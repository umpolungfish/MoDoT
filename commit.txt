Take the free lane when every paid door is shut

The provider ladder only helps when some other key is funded. When all of them
are out — openrouter 402, deepseek 402, gemini 429, which is the live state —
it demotes to a second broke door, and the run closes at N with a provider CUT
having never reasoned. A cut refutes nothing, so taking one while a reachable
door remains is pure loss.

OpenRouter's `:free` models bill nothing and answer to the same key that just
returned 402: a spent balance closes the paid lane, not the account. So the free
lane is tried FIRST on a fatal error, ahead of the provider ladder, and unlike
the ladder it fires on a pinned provider too, because pinning a provider is a
choice about which provider, not a preference for silence over an answer.

FREE_MODELS is ordered strongest first, largest context first, and carries the
curl that regenerates it. FREE_LANE caches the model that answered so later
rounds go straight there instead of re-hitting the broke door and paying the
402 and the latency again.

429 and "quota" now read as fatal. They were not, so an exhausted Gemini key
returned a rate-limit error that no retry against the same door could clear, and
the run sat there instead of routing around it.
