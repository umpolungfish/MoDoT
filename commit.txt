Give ask its own --lean audit [repair], the general Lean-to-ELF procedure

The compile-then-vox-then-repair pipeline already existed as a p4ramill
shell script most people would never think to go looking for. `lean`/`lean
audit` were also only reachable through the agent's own TOOL: line parser,
never as something a person could type at the prompt.

`ask --lean <path.lean>` still elaborates and reports the kernel's errors.
`ask --lean audit` now shells straight to the (just-extended)
vox_elf_audit.sh: compile every module's generated C to a real ELF, vox-read
the compiled machine code's own control-flow census. `ask --lean audit
repair` adds the rest of the general procedure in one call: for every
function vox itself flags B or F, decompose its word mark by mark and run it
through mOMonadOS's insert for single-glyph repairs.

Registered as a real --lean flag (--imasm already had one, --lean never
did), so this is reachable directly, not only from inside an agent run.
Rebuilt ask.bin so the deployed ./ask wrapper carries it too, the same gap
the ⊡ rename left behind for the wrapper earlier this session.
