Rebuild ask.bin: it was four days stale, from before the ⊡ rename

The ? showing up in place of the winding value on sk_forge, skolem_function
and skolem_normal_form's tuples wasn't a source bug. The catalog has always
carried the right key and value for all three, checked byte for byte in both
copies plus the live-crawler one. click.rs already has the fix, it's the same
commit that swapped the old mark for ⊡ across the repo.

ask.bin, the actual binary every ./ask wrapper script in the tree execs, was
built four days before that rename landed. It still carried the old glyph in
its compiled-in primitive table, so it looked up the wrong key against the
now-renamed catalog and got nothing back for the winding axis, which broke
more than the display: the missing value took out the D-W live-pair charge,
so the click logic reported no bond where a fresh build correctly finds a
cross-link. Rebuilt from current source and confirmed clean through the top-
level ./ask wrapper.
